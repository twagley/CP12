The assignment

Use HTML and CSS to display a game board. Use color and font changes, positioning, CSS selectors, and style containers to show your skills.

You may wish to add a table of scores on your page, and/or a list of simple instructions in order meet the evaluation requirements.

Evaluation

  • ___/10 HTML: Quality of HTML code. For full marks, you must include:
    1. a <span>
    2. a <div>
    3. a heading
    4. a table
    5. a list or paragraph
  • ___/10 CSS: Quality of CSS code, choose ANY TEN of:
    1. applying a style to a tag
    2. applying a style to an #ID
    3. applying a style to a .class
    4. applying a color: or opacity:
    5. applying a background-color:
    6. changing a font-size:
    7. changing the font-family:, font-style:, or font-weight:
    8. changing the width: or height:
    9. changing the text-align:
    10. making a border:
    11. changing the position:
    12. placing something using left: or top:
    13. changing stack order with z-index:
    14. adding a CSS animation
  • ___/10 STYLE:, including:
    1. Use the correct filename for your assignments
    2. Add your name as the code author
    3. Keep the change log updated
    4. Capitalizing HTML tags
    5. x3 Formatting code with tab indents
    6. Use comments to communicate
    7. Avoid long lines of code
    8. Keep your CSS inside your <head>

Hidden Agenda

  • No, it does not have to be a game board. Make anything fun that you want that demonstrates the skills you have learned.
  • Use what you have learned about CSS to create something
  • Use good style to communicate clearly
  • Know the difference between <div> and <span>
