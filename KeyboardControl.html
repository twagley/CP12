Sniffing keystrokes

In the Javascript events lesson, you were able to read the keystrokes as they were entered into a text box. This worked by using code like: <input type="text" id="inputLine" onkeypress="doSomeFunction(event);">

But that only worked when you had the cursor in the text box. For many things, like controlling games, you want to have the keyboard react no matter where the cursor is.
