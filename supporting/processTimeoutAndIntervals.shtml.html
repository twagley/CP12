Javascript will put anything between the two quotes inside the string. So these two statements below <strong></strong>are exactly the same</strong>: </p> <pre><code>var frenchGreeting = "Bonjour!"; var frenchGreeting = 'Bonjour!';</code></pre> <p> However, Javascript will throw an error if the string surrounded by quotes contains the same kind of quote. </p> <p> There are a couple ways around this. One is to escape the quotes in the string with an <strong>escape character</strong>, which in Javascript is a backslash: <code>\</code> </p> <pre><code>var brokenString = 'It's a beautiful day...'; // brokenString will cause an error because of the apostrophe in "it's" var workingString = 'It<span class="withborder">\</span>'s a beautiful day...'; // The escape character tells Javascript to read the apostrophe as part of the string</code></pre> <p> Another way to deal with this is to surround the quote with a different kind of quotation mark: </p> <pre><code>var brokenString = 'It's a beautiful day...'; var workingString = <span class="withborder">"</span>It's a beautiful day...<span class="withborder">"</span>;</code></pre> <p>A common example:</p> <pre><code>document.getElementById('outputID').innerHTML = "&lt;strong id="strongID">You win!&lt;/strong>"; // fail document.getElementById('outputID').innerHTML = "&lt;strong id=\"strongID\">You win!&lt;/strong>"; // win!</code></pre> <h4>Adding strings and numbers together</h4> <p> If you add a number and a string together, it will add them both together like strings. </p> <pre><code>var answer = 4 + 8; // answer now holds 12 var answer = '4' + 8; // answer now holds '48' var newSize = 16 + '10px'; // newSize now holds '1610px'</code></pre> <h4>Converting strings to numbers</h4> <p> In order to around the string to number addition problem, it is handy to convert strings to numbers. This is especially important when you read information from an <code>&lt;input></code> value or from a <code>.style</code> property of an element. </p> <p> We can use two special function to extract numbers from strings: <code>parseInt()</code> for extracting integers, and <code>parseFloat()</code> for extracting floating decimal numbers. The words <strong>parse</strong> means to extract information from some data. </p> <pre><code>var parsedDecimal = parseFloat( '3.141592654 is a rough approximation of pi' ); // parsedDecimal now holds 3.141592654 var parsedInteger = parseInt( '3.141592654 is a rough approximation of pi' ); // parsedInteger now holds 3 var newSize = 16 + parseInt( '10px' ); // newSize now holds 26 var newSize = (16 + parseInt( '10px' ) ) + 'px'; // newSize now holds '26px'</code></pre> <h2>Check your understanding</h2> <p> What is inside <var>answer</var> in the following example:<br /> <code>var answer = 8 + 12;</code><br /> <span class="question" data-answer="answer contains 20"></span> </p> <p> What is inside <var>answer</var> in the following example:<br /> <code>var answer = 8 + '10px';</code><br /> <span class="question" data-answer="answer contains '810px'"></span> </p> <p> What is inside <var>answer</var> in the following example:<br /> <code>var answer = 'Hello world' -
