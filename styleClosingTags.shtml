Close as you go...

One of the causes of errors in coding is forgetting to add the closing tag, for example not adding </li> after <li>.

I like to type both pairs of tags (<li></li>) at the same time, and then go back and put the content in the middle directly afterward (<li>list item content</li>). This way I never forget the closing tag.

Some editors, like Notepad++ have an option to automatically add the closing tag as soon as you have finished opening it. Some people do not like this, but some people do.

In Notepad++, you can turn this on and off by going to: Settings → Preferences... → Auto-Completion → XML/HTML close tag.
