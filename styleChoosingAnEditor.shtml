Thankfully there are other editors in the world besides Notepad.

The coding environment that programmers use is the source of a great deal of debate. Personally, it depends on how I am using it: to edit this site, I work on GitHub's server side directly.

Sublime Text is my favourite to use for personal development, such as doing assignments for this class. It's free and works on both Win and Mac. At home, you can use whatever you want. Take a look at Visual Studio Code: it is pretty good!

The school computers do not allow us to install anything permanently. There are other great editors out there, but it is best to use them at home.

Why use a programming editor?

  1. Syntax highlighting - different kinds of code are different colours
  2. There are often error-checking tools built-in
  3. Programming code autocomplete! (Soooooo good!)
  4. Formatting helpers, like bulk tabbing
  5. And so much more

After a while you get so used to writing in programming editors that word processors start to seem awkward and slow. I do all of my coding in programming editors. I can't go back!
