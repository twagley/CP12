Hello color!

CSS allows you to format your pages thoughtfully.

In the old days, people would add the formatting code right inside the HTML.

This turned into a maintenance nightmare: if you wanted to change all the headings in a page, you have to edit each one individually. In long documents this was a lot of work. And you couldn't use programming to change formatting easily at all.

Then came CSS

CSS solved a lot of problems:

  • it organized formatting by encouraging coding all the style information inside the head of the document.
  • it made it possible to format elements in a document by tag - like p, h3 or li, for example.
  • it made it possible to use Javascript to change the formatting as needed
  • and it still allows you to apply custom formats to small parts of code that are special cases.
