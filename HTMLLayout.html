header code goes at the top, for a page title, for instance.
nav code goes underneath and would typically contain links to other pages.
section is like a headline.
article is like a collection of paragraphs to read.
sections can be repeated.
articles can be repeated, too.
aside is for sidebars: additional explanations for a page, or sidebar navigation.
footer code is for the material at the bottom of the page, typically legal information and less-used informational links.
