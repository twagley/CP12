Reduce the time between save and reload

This tip is a small one, but it does save time.

If you are using Notepad++, there is a command to run your code in Chrome, Firefox, etc. Go to the menu and choose Run → Launch in Firefox (or whatever browser you are using). This will save you from having to drag your files into the browser.

Heck, you can even memorize the keyboard shortcuts:

  • control-alt-shift-X = Firefox
  • control-alt-shift-R = Chrome
